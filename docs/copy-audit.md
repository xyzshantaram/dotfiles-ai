# Copy audit — old wizards to the expense-split web wizard

Ticket U1 proof. This table maps every user-facing string of the old terminal surfaces to its new
home in `wizards/expense-split.ts` and `wizards/expense-split/`, or records why it is gone.

Rules used:

- Old surfaces: the ten files listed in the ticket. User-facing strings only. Log lines and code
  comments stay out.
- The old `splitter.ts`, `splitter-cliffy.ts`, and `splitter-kit.ts` share most copy. One row covers
  one unique string and cites all three sources.
- Status `carried` means the same copy (or a near match) shows in the new wizard. `missing` means
  the feature still exists in the new wizard but the copy is gone. `dropped` means the feature
  itself is gone, with the reason.
